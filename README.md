# QuanTriDAPM

## De tai
Xay dung he thong Website ban thiet bi dien tu Online

## Thong tin nhom
Du an mon Quan tri du an phan mem - Nhom 3 thanh vien.

## Cong nghe
PHP, MySQL, HTML, CSS, JavaScript.

## Cau truc du an
- config/: Cau hinh ket noi co so du lieu.
- database/: Co so du lieu MySQL.
- include/: Cac ham dung chung.
- classes/: Cac lop xu ly nghiep vu.
- css/, js/, img/, image/: Giao dien va tai nguyen.
- module/: Cac module chuc nang.
- subpage/: Cac trang thanh phan.

## Cai dat
1. Cai dat moi truong PHP va MySQL.
2. Import database/computer_store.sql vao MySQL.
3. Cap nhat config/config.php cho phu hop moi truong.
4. Chay website tren may chu PHP.

## Phan cong
- Nguoi 1: Cau hinh, giao dien, san pham, lien he va chinh sach.
- Nguoi 2: Tai khoan, gio hang, don hang va binh luan.
- Nguoi 3: Quan tri he thong.
